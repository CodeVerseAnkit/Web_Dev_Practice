The Cascade Algorithm

The cascade algorithm refers to several distinct mathematical and computational processes, depending on your field. Most commonly, it is the rule-resolving engine in CSS that determines which conflicting style rules apply to a web element. It evaluates rules based on Origin, Importance, Specificity, and Order of appearance.

The cascade algorithm has 4 distinct stages

  1. Position and order of appearance
  2. Specificity
  3. Origin
  4. Importance

The order of Specificity

!important > Inline style > ID selector > Class or attribute selector > Element selector > Universal selector

Specificity Calculation

  • Universal selector = 0
  • Element selector and pseudo element = 1
  • Class selector and attribute selector and pseudo classes = 10
  • ID selector = 100
  • Inline style = 1000
  • !important = 10000
